# Hospital Emergency Room Dashboard

## Project Overview

This project analyzes Emergency Room operations using Power BI.

### KPIs

- Total Patients
- Average Wait Time
- Patient Satisfaction
- Referral Analysis

### Key Insights

- 9,216 patient visits
- 35.3 minute average wait time
- 40.7% patients exceeded target wait time
- Weekends experienced highest patient volume

### Recommendations

- Increase weekend staffing
- Improve triage efficiency
- Enhance patient communication
- Optimize peak-hour resource allocation
